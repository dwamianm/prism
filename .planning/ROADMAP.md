# Active roadmap

The historical v1.0 roadmap is archived at
`archive/v1.0-legacy/ROADMAP.md`. The active roadmap is maintained in
`memory_bank/GOALS.md` and follows evidence rather than the old phase sequence:

1. Preserve and verify production correctness, isolation, recovery, and API
   compatibility.
2. Run a matched, held-out comparison against current memory alternatives.
3. Close the interactive-task, conflict, temporal, and value-fidelity gaps.
4. Promote only changes that pass preregistered quality and regression gates.
5. Publish a release only after installed-package and backend checks pass.
