# Planning state

The original v1.0 GSD milestone is historical. Its completed phase plans and
root planning documents are preserved under:

- `milestones/v1.0-phases/`
- `archive/v1.0-legacy/`

The active product goals and evidence-driven handoff live in
`memory_bank/GOALS.md`. The files in this directory are intentionally short
pointers so an old GSD milestone cannot be mistaken for current acceptance
criteria.
