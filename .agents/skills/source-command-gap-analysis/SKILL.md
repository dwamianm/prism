# source-command-gap-analysis

Use this skill when the user asks to run the migrated source command `gap-analysis`.

## Command Template

Spin up 3 sub agents to do a gap analysis, a security audit of the current work and a code quality review. Publish the findings into an MD file in the memory-bank/reviews folder with a naming convention that points to recent work. Be thorough in the analysis and don't be afraid to ask the developer clarifying questions if necessary.
